# 3D Scene Models & Assets (`models/`)

Simulation Description Format (`.sdf`), 3D visual/collision meshes (`.glb`),
and Intrinsic Scene Object manifests (`.textproto`) bundled into
`//:omts_solution`.

## Assets

| Directory | Asset ID | Description |
| :--- | :--- | :--- |
| [`bit_grid/`](bit_grid/) | `ai.intrinsic.bit_grid` | 10×10 bit rack, 35 mm pitch, seats at 47 mm (UR5e cell). Generated by `makera_carvera/build_carvera.py`. |
| [`bit_grid_21/`](bit_grid_21/) | `ai.intrinsic.bit_grid_21` | Same rack at 21 mm pitch for the SO-101 cell; deployed as instance `bit_grid`. |
| [`makera_bits/`](makera_bits/) | `ai.intrinsic.makera_bit_<id>` | One asset per bit in Makera's Carvera catalogue (81, incl. the UV solder-mask tool), instances `bit_<id>`, origin at the collar seat, `grip_frame` on the shank. `makera_bits.json` gives shank sizes to `move_bit`. Generated by `build_bits.py`; collar and some lengths are estimates. |
| [`so101/`](so101/) | `ai.intrinsic.so101_hardware_module` | SO-ARM101 5-DOF arm from TheRobotStudio's official meshes and URDF (Apache-2.0, `LICENSE.SO-ARM100`). Sim-only hardware device on the generic Gazebo HWM stub; IK `kinematic_chain`. Generated by `build_so101.py`. |
| [`so101_gripper/`](so101_gripper/) | `ai.intrinsic.so101_gripper` | SO-101 gripper jaw (`jaw_joint`, negative closes) with `tool_frame` on the fixed jaw face; set through `update_world`. |
| [`so101_stand/`](so101_stand/) | `ai.intrinsic.so101_stand` | Plywood pedestal for the SO-101 with frames `arm_mount` and `grid_mount`. |
| [`carvera_bench/`](carvera_bench/) | `ai.intrinsic.carvera_bench` | Küpper workshop bench under the Carvera in the SO-101 cell: 60 × 60 cm, top at 0.84 m, one drawer above one door (sizes from a retailer listing; panels estimated from photos). Turned so the door is under the Carvera's front. `top_center` frame. |
| [`robot_cart/`](robot_cart/) | `ai.intrinsic.robot_cart` | Workbench on casters carrying the SO-101 and the bit grid, top level with the ATC seats (`top_center` frame). |
| [`camera_mount/`](camera_mount/) | `ai.intrinsic.camera_mount` | Wrist bracket mounting the Orbbec Gemini 3D camera to the robot flange. |
| [`carvera_tool_holder/`](carvera_tool_holder/) | `ai.intrinsic.carvera_tool_holder` | Makera Carvera ATC tool holder (collet nut + bit), `grip_frame` for a top-down grasp. No longer deployed; replaced by `makera_bits/`. |
| [`cnc_enclosure/`](cnc_enclosure/) | `ai.intrinsic.cnc_enclosure` | Generic IMTS CNC enclosure with sliding door (no longer deployed; kept for reference). |
| [`makera_carvera/`](makera_carvera/) | `ai.intrinsic.makera_carvera` | Makera Carvera desktop CNC, deployed as instance `cnc_enclosure`: hinged lid (`lid_joint`, 0 closed / 1.4866 rad open), bed, parked gantry, ATC rack with frames `atc_slot_0`..`atc_slot_6`, `bed_center`. Generated by `build_carvera.py`. |
| [`omts_enclosure/`](omts_enclosure/) | `ai.intrinsic.omts_enclosure` | Main robot cell safety enclosure and worktable geometry. |
| [`raw_stock_2x3x5/`](raw_stock_2x3x5/) | `ai.intrinsic.raw_stock_2x3x5` | 2" × 3" × 5" raw stock billet used for pose estimation and manipulation. |
| [`schunk_egp_64nnb/`](schunk_egp_64nnb/) | `ai.intrinsic.schunk_egp_64nnb` | Schunk EGP 64 pneumatic 2-finger parallel vise with articulated jaw joints (`jaw_l`, `jaw_r`). |
