# ATC tools (`tools/atc/`)

`move_bit` moves Carvera ATC tool holders between the 10 x 10 bit grid
(`bit_grid`, slots `grid:R,C`) and the Makera Carvera's tool rack (`atc:1` ..
`atc:6`; slot 0 is the probe). It finds the holder at the source slot in the
belief world, opens the Carvera lid when the ATC is involved, and picks and
places top-down with the Hand-E.

```bash
bazel run -c opt //tools/atc:move_bit -- --list
bazel run -c opt //tools/atc:move_bit -- --move=grid:0,0:atc:1
bazel run -c opt //tools/atc:move_bit -- --fill_atc    # empty T1..T6 <- grid
bazel run -c opt //tools/atc:move_bit -- --empty_atc   # T1..T6 -> free cells
```

Layout: `configs/omts/bit_grid.updates.pbtxt` (grid pose and the 100 holders
`bit_00` .. `bit_99`, row-major), `configs/omts/carvera_atc.updates.pbtxt`
(ATC approach frames). Models: `models/bit_grid`, `models/carvera_tool_holder`,
generated by `models/makera_carvera/build_carvera.py`.
